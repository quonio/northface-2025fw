# 商品情報リソース

## 商品データ管理

### 商品情報スプレッドシート
- **URL**: https://docs.google.com/spreadsheets/d/1EY_Ap_UhrBf1hDniQc96WV_y8UZkBTEcw38lAGMbtgM/edit?gid=1926603981#gid=1926603981&range=7:7
- **用途**: 商品情報の調整・管理に使用
- **内容**: 商品の詳細情報、価格、在庫状況などの情報を管理

### プレゼンテーション資料
- **URL**: https://docs.google.com/presentation/d/1idgJ8aYUelfhTy1McD0MkEMrWOs9Imm-Qat6k2xjRPM/edit?slide=id.p#slide=id.p
- **用途**: 商品展開やデザインの参考資料
- **内容**: ビジュアルレイアウト、商品配置、デザインガイドラインなど

### 使用方法
1. 上記のスプレッドシートにアクセス
2. 必要に応じて商品情報を更新
3. 更新後は関連するコンポーネントのデータを同期
